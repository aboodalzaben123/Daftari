# ✍️ دفتري

تطبيق دفاتر ملاحظات بخط اليد يشتغل بالمتصفح وبيتثبّت كتطبيق على الآيباد والجوال والكمبيوتر.

## الميزات
- دفاتر ومجلدات ووسوم، وبحث.
- أقلام ومحاة وتظليل ومسطرة وأشكال وتحديد.
- قوالب ورق: سطور، مربعات، نقاط، كورنيل، و**دفتر هوامش الزوايا** (صناديق ملوّنة بزوايا الصفحة بمدى صفحات ونص ولون).
- سطور للحل، وتنصيف الصفحة عمودي وأفقي.
- حاسبة ورسم اقترانات، ولاتيكس مع صناديق (تعريف، قانون، مثال، حل...).
- استيراد PDF كدفتر، ونسخة احتياطية.

## التثبيت كتطبيق
- **آيباد / آيفون (Safari):** زر المشاركة ← إضافة إلى الشاشة الرئيسية.
- **أندرويد / كمبيوتر (Chrome):** قائمة المتصفح ← تثبيت التطبيق.

بعد أول فتح بيشتغل بدون إنترنت (بعض الخصائص مثل بايثون بتحتاج إنترنت).

## ملاحظة عن البيانات
الدفاتر بتنحفظ **داخل المتصفح على هالجهاز** مش على سيرفر. لنقلها لجهاز ثاني أو لحمايتها استخدم زر النسخة الاحتياطية (سهم التنزيل بالشاشة الرئيسية).

## النشر على GitHub Pages
1. ارفع محتويات هالمجلد للمستودع (الملف `index.html` لازم يكون بالمجلد الرئيسي).
2. Settings ← Pages ← اختار فرع `main` والمجلد `/ (root)`.
3. بعد دقيقة بيطلع الرابط.
